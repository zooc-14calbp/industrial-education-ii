# 進路の統計とグラフを読む演習案

2026年11月4日。Ⅱ第3・9回を中心とし、第10回の情報活用能力、第15回の進路相談とも関連付ける。Ⅰでは第4回の進路の背景、第9回の調査の読み方へつなげる。グラフを作る操作より、対象・分母・区分・限界を踏まえて説明する学習を優先する。

## 使用する実データ

[文科省 高等学校卒業者の学科別進路状況](https://www.mext.go.jp/a_menu/shotou/shinkou/genjyo/021203.htm)の令和7年3月卒業者の表から、農業・工業・商業・水産・普通科の5区分を抜粋した。出典は令和7年度学校基本統計。各行は当該学科の卒業者を分母にした割合で、学科の人数は同じではない。学校基本調査の[全日制・定時制の卒業後の状況の統計表](https://www.e-stat.go.jp/stat-search/files?cycle=0&layout=datalist&page=1&tclass1=000001236922&tclass2=000001236962&tclass3=000001236975&tclass4=000001236979&toukei=00400001&tstat=000001011528)と対象を照合する。通信制等を含む別集計や中等教育学校等を含む集計と混ぜない。

[グラフと問いのPDF](statistics-exercise.pdf)／[グラフPNG](statistics-pathways.png)／[抜粋データCSV](statistics-pathways.csv)

学科は原表に沿った順で並べ、割合の大小を学校・生徒の優劣として示さない。5区分は全学科の一覧ではなく、全体の構成比を計算するための標本でもない。「専門高校計」の値は、この5行の単純平均では求められない。

原表の「大学・短大等」は大学学部のみを意味しない。「専修学校・公共職業能力開発施設等」も専門学校だけの区分ではない。原表の注記に従い、就職者には就職進学者を含めない。「その他」の個々の状況は、この集約区分から判断しない。

## 10分程度のThinking time

1. グラフの対象年、分母、単位、5行を選んだ範囲を確認する。
2. 二つの学科を選び、数値を根拠に「この図から言えること」を一文書く。
3. 「この図から言えないこと」を一文書く。
4. 生徒へ説明する前に、次に見る資料と確認事項を一つ挙げる。

必須の計算は設けない。任意で二つの割合の差を求める場合は、百分率の差を「ポイント」で表す。棒の長さが同じ100％でも、人数が同じではない点を確かめる。

## 解説の例

言えること：この集計では工業科の就職者の割合は63.3％、商業科は33.6％である。大学・短大等や専修学校等へ進む区分もあり、就職だけの経路ではない。

言えないこと：この差だけでは、教育の良し悪し、学力や適性、本人の希望、家庭事情、将来の収入や満足度は判断できない。個々の学校や生徒にも、そのまま当てはめられない。卒業時点の分類から、その後の転職や学び直しも分からない。

次の確認例：進学を考える学校の教育課程と卒業後の経路、集計年度と人数、進路区分の内訳を確認する。「どちらが良いか」を割合だけで決めず、生徒がどのような活動を学びたいかを具体的に尋ねる。

## 別の統計へ広げる順序

まず一つの図で読み方を学び、次に次の題材へ移る。毎回別の大量の統計を追加しない。

| 題材 | 主な回 | 確認すること |
|---|---|---|
| 中高・高大等の進学 | Ⅰ第4回 | 年度、卒業者と同年齢人口の違い、分子・分母、地域の条件。 |
| 学科別の卒業後の進路 | Ⅱ第3・9回 | 人数と割合、進路の区分、学科と学校の違い。 |
| 産業別の就職先 | Ⅱ第2・4回 | 卒業者全体か就職者だけか。産業分類と職業分類の違い。 |
| 学力や学習状況 | Ⅰ第9回・Ⅱ第10回 | 対象学年、参加範囲、測る内容、質問項目と得点の関係。相関から原因を断定しない。 |
| 学びの継続・中途退学 | Ⅱ第13回 | 対象課程、年度、分母、理由区分。区分から個人の原因を推測しない。 |

統計を使ったメモも毎回提出する必要はない。資料整理として取り組めるため、本人や家族の経験を開示せずにレポートA・Bへつなげられる。
