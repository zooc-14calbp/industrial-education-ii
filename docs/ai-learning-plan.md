# AIを学ぶ内容と各回への配置

> 2026年11月5日の実装状況は[動画・スライドの差替状況](media-replacement-status.md)を参照してください。以下の設計時の記述より、差替済み回の利用案内を優先します。

2026年11月4日。AIを独立した新しい一回として足すのではなく、Ⅰの教材・授業づくりと、Ⅱの仕事・情報・相談へ関連付ける。以下は改訂教材の設計で、現行動画への反映前である。

## 学習の焦点

AIには分類・予測・認識等を行うものもあり、文章・画像等を生成する生成AIだけではない。専門高校と社会の仕事を知る文脈では、どの作業を支え、どこに人の判断・確認・責任が残るかを考える。特定の職業がなくなる、使える人だけが有利になる等の一方向の予測を結論にしない。

学校での生成AIの扱いは、[文科省の掲載資料](https://www.mext.go.jp/zyoukatsu/ai/)と[初等中等教育段階における生成AIの利活用に関するガイドライン Ver.2.0](https://www.mext.go.jp/content/20241226-mxt_shuukyo02-000030823_001.pdf)を参照する。確認日2026年11月4日、文書公表日は2024年12月26日。第2章の基本的な考え方、第3章の共通事項、教職員が使う場面と児童生徒が学習で使う場面を分けた説明を読む。掲載ページで版の変更を確認してから収録する。

ガイドラインは法令そのものとは区別し、個人情報、著作権、利用規約・年齢条件、学校や設置者の方針等を場面に応じて確かめる。児童生徒が使う条件と、大学生・教員が使う条件を同一視しない。初学者向けには、目的、出力の確認、入力情報、誰の判断が必要かの四点に絞って説明する。

## ⅠとⅡの分担

| 回 | 取り上げる内容 | 問いの例 |
|---|---|---|
| Ⅰ第10回 | 画像等を使う技術の性能と、生徒の学習の証拠 | うまく処理できたことと、何を学んだかを示す情報は同じか。 |
| Ⅰ第11回 | 教材・説明案の候補を点検する | 架空のAI説明案の数値・単位・根拠をどう確かめるか。 |
| Ⅰ第12回 | 安全に関わる判断の情報源 | 自然な説明だけで、機器の作業手順として使ってよいか。 |
| Ⅰ第14回 | 教員の準備と教材の更新・引継ぎ | 原稿や例を変えたとき、確認した根拠と条件をどう残すか。 |
| Ⅱ第2回 | 産業や職業の中の作業の変化 | 一つの作業の自動化と、職業全体の役割の変化を分けられるか。 |
| Ⅱ第7回 | ビジネスや情報の学びと生成AI | 商品紹介の案のどこを、人が資料で確認する必要があるか。 |
| Ⅱ第10回 | 情報活用能力と専門高校への接続 | もっともらしい表や説明の、出所・単位・比較条件を確かめられるか。 |
| Ⅱ第15回 | 進路相談の情報とAI・検査の限界 | 一つの候補を示す出力から、本人の進路を決めてよいか。 |

中心はⅠ第11回とⅡ第2・10・15回であり、他の回は必要な接続だけを短く扱う。各回に同じAI入門を追加しない。

## 教室で使う固定例

Ⅰ第11回では、教師が作成した誤りを含む説明案を「架空のAI出力例」と明示する。例えば「120mmは1.2m」と書かれた文と、単位の対応を示す資料を渡し、誤り、正しい表現、確かめ方を示す。これは実際のサービスの出力記録ではない。AIの失敗例を眺めるだけでなく、正しい資料を使って説明を修正するところまで行う。

Ⅱ第15回では、「食品に関心があるので一つの進路に決定する」といった模擬の説明案を用い、関心を具体化する質問、複数の学習経路、未確認の条件、本人の選択を補う。AIを相談相手や判断の代行者として生徒の個人情報を入力する活動にはしない。

受講者のAIサービスへの登録・契約、個人の診断結果、実際の生徒情報の入力は不要とする。固定の資料だけでも同じ目標へ取り組めるようにする。操作できたかではなく、どこを何の根拠で確かめたかを考える。新しい提出レポートは設けない。

## 動画と資料への反映

Ⅰでは第11回の教材比較の一部を固定例へ差し替え、Ⅱでは第2回の作業の変化、第10回の情報の確認、第15回の相談説明へ取り込む。実際の生成サービスの画面を長く録画するより、仕組み・判断・根拠が分かる独自の図と説明を使い、サービスの仕様変更で講義全体を録り直す必要を減らす。
