# 統計図表を講義用に作り直す方針

2026年11月6日。Ⅰ・Ⅱ共通の制作方針です。各回の本文を見直す際に、元表の数値から講義用の図を順次作成し、本文・スライド・学習ガイド・動画へ反映します。すべての回を一度に差し替えるための予定表ではありません。

## 図を作る前に確かめること

1. 文科省、e-Stat、OECDなどの公開元表を探し、表番号・公開年・基準年・対象・単位・分母を記録する。速報値と確定値を混ぜない。
2. 原表の分類と授業で使う言葉の対応を確かめる。「工業科」と「職業課程」のように一致しない分類は、同じものとして扱わない。
3. 計算を再現し、欠測・非該当・不明・丸めを確認する。比率を計算し直した場合は、分子と分母を残す。
4. 学生が読み取る問いを先に決め、軸・単位・凡例・対象年・出典を図の中にも置く。配色だけに意味を担わせず、数値と文章でも読めるようにする。
5. 図の説明には「読み取れる事実」「推測にとどまること」「この図からは分からないこと」を短く示す。元表へのリンクを本文とガイドに付ける。

## 差し替えの順序

| 優先 | 回 | 次の作業 |
|---|---|---|
| 着手済み | Ⅱ第11回 | OECDの後期中等教育・職業課程の実数値を再作図し、比較の分母と加盟国の範囲を説明する |
| 次 | Ⅰ第4回 | 学校基本調査の中高・高大進学の原表を確認し、年次と地域の比較図を作る |
| 次 | Ⅱ第8回 | 学科別卒業後の進路図にe-Statの元表番号と通信制の扱いを加える |
| その後 | Ⅱ第1回など | 既存の産業構成図や進路図を、原表・計算・図の表記の順に再点検する |

写真は学校・施設や仕事の具体像を示す目的で使い、撮影者・権利・撮影時期を確認します。説明に必要な画像がなければ、写真を数合わせで増やしません。公開元表から再作図できない場合は、出典の図へリンクして理由を記録します。
