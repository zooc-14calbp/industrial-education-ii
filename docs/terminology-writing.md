# 専門用語の補い方

学生が初めて出会いそうな語は、使う場所で意味が分かるようにする。短い説明で足りる場合は初出の語に括弧書きを添える。説明が長くなる場合は、見出しや本文を平易にし、原文の語と対応する説明をスライドの注やガイドに置く。注にも本文と同じく読みやすい文字サイズと配色を使う。

用語を言い換える際は、意味の範囲を狭めたり広げたりしていないか、原資料で確認する。制度や判決では、用語の意味と、その文書が示す条件・判断を分ける。

| 用語 | 初出で添えられる説明 |
|---|---|
| 大綱的 | 全体の枠組みを示す |
| 裁量 | 自分で判断できる範囲 |
| 款 | 節の中の区分 |
| 分母 | 割合を求めるときの、もとにする人数や件数 |
| 出願資格 | 申し込みができる条件 |
| 因果関係 | 一方がもう一方の変化を引き起こす関係 |

例えば「出願資格がある」は「申し込みができる条件を満たす」と書く。条件を満たすことと、選考を経て入学することは別の段階として説明する。
