# 授業で前提とする知識と、用語の補い方

木質材料学のような専門科目では、学生が初めて学ぶ用語を見込んで、授業の冒頭で定義する。工業科教育論でも、授業者が共有されていると見込む知識と、学生が使える知識にはずれがありうる。とくに、新聞や学校の文書に出てくる日常語に近い言葉や、制度・仕事の仕組みは、授業者が前提にしやすいため点検する。

「学生なら知っている」「大人なら分かる」といった見込みを、授業で必要になる具体的な知識に置き換える。語を見聞きした経験、意味を説明できること、事例に当てはめて判断できることは、それぞれ分けて考える。工業高校の教育課程を読んだ経験など、学ぶ機会には個人差がある。ある語へのなじみの薄さから、学生全体の学力を判断しない。

教材を作る際は、説明や演習の結論を理解するために、学生が何を知っている必要があるかを一つずつ確認する。必要な前提は、使う場面の直前に短く補う。

| 授業で使う言葉 | 一緒に示す場面や問い |
|---|---|
| 履修 | 「その科目を学ぶこと」。学ぶ科目を示す表と、単位を取った記録を見比べる。 |
| 求人票 | 「会社が、どんな仕事をする人を、どんな条件で募集しているかを示す書類」。架空の求人票で、仕事内容と勤務時間の欄を探す。 |
| 進学率 | 「ある集団のうち、次の学校などへ進んだ人の割合」。架空の表で、何人のうちの何人を数えたかを確かめる。実際の統計では対象と定義も確認する。 |

理解を確かめたいときは、提出不要の短い問いと答えを同じ教材に置く。例えば「出願資格があると書かれている。この文から何が分かるか」と問い、「申し込める条件を満たしている。入学できるかは選考後に決まる」と示す。自分の学校歴や家庭の経験を話さずに答えられる架空例を使う。

## 説明を添える位置

学生が初めて出会いそうな語は、使う場所で意味が分かるようにする。短い説明で足りる場合は初出の語に括弧書きを添える。説明が長くなる場合は、見出しや本文を平易にし、原文の語と対応する説明をスライドの注やガイドに置く。注にも本文と同じく読みやすい文字サイズと配色を使う。

短い定義を付けても意味をつかみにくい語は、具体的な問いを先に出す。例えば「法的根拠」は、「学校が必ずやることは何か」「その決まりはどこに書いてあるか」と順に問い、測定の授業など身近な場面で考える。その後で、決まりを支える法律や規則の条文を「法的根拠」と呼ぶことを伝える。

用語を言い換える際は、意味の範囲を狭めたり広げたりしていないか、原資料で確認する。制度や判決では、用語の意味と、その文書が示す条件・判断を分ける。

| 用語 | 初出で添えられる説明 |
|---|---|
| 大綱的 | 全体の枠組みを示す |
| 裁量 | 自分で判断できる範囲 |
| 款 | 節の中の区分 |
| 分母 | 割合を求めるときの、もとにする人数や件数 |
| 出願資格 | 申し込みができる条件 |
| 因果関係 | 一方がもう一方の変化を引き起こす関係 |

例えば「出願資格がある」は「申し込みができる条件を満たす」と書く。条件を満たすことと、選考を経て入学することは別の段階として説明する。


## 各回の確認の置き方

本文の到達目標の後に、本題につながる短い問いと答えを一組置く。問いでは用語の定義を復唱するだけでなく、架空の場面や資料で何を確かめるかを聞く。答えを見ても曖昧なら、該当する説明・表・原文に戻れるようにする。指導要領では、問いを立て、該当箇所を開き、意味を言い直して根拠を示す練習を取り入れる。答えを探し直す過程も授業中に示す。

## 同じ音の言葉を扱うとき

「協働」と「共同」のように読みが同じ言葉は、漢字の表記と、文書の中で何を指すかを分けて確かめる。原文の表記を読む場面では原文どおりに示す。活動や学習の記録では、誰が何を見せ合い、どう相談し、何を決めたかが伝わる言葉を使う。語を置き換えたときは、読み手に伝わる行動や判断が具体的になったかを確かめる。
