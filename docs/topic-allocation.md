# ⅠとⅡの話題の分担

2026年11月4日。Ⅰで原文・専門科目・授業を知り、Ⅱで社会・仕事・進路の説明と支援へ使い直す。両科目で同じ解説を全て繰り返さない。

| 話題 | Ⅰの役割 | Ⅱの役割 |
|---|---|---|
| 法と指導要領 | 第5回を中心に第6～8回で具体化 | 第1回の位置付け、第3回の資格、第9・11・14回の制度へ応用 |
| 工業の専門分野 | 第2・3・6・7・8・11回へ分担 | 第4回で学びと進路へ使い直す |
| 産業と仕事の基礎 | 第4回で歴史と地域との関係 | 第2回で産業・職業・働き方と構成比 |
| 資格と免許 | 第14回は教員免許を中心にする | 第3回で種類と読み方、第4～8回で代表例、第9・15回で経路と条件 |
| 統計とグラフ | 第4回の進路、第9回の調査 | 第2回の産業、第3・9回の進路、第13回の継続条件 |
| 生徒理解と支援 | 第9回で学習の目標と支援 | 第10回で学校間の接続、第13・14回で学習機会と相談 |
| 課題研究 | 第8回で科目の目的、第10回で実践を読む | 第11回の体験・振り返りへ関連付ける |
| ICTと情報活用 | 第11回で教材と説明、第10回で技術と学習の証拠 | 第10回を中心に中学校と専門高校の導入を対応させる |
| AI | 第11回の教材点検を中心、第10・12・14回で関連付け | 第2回で仕事の変化、第7・10回で情報の検証、第15回で相談の判断 |
| 職業指導の考え方 | 職業教育の目的と授業の学習を支える | 第1回の意味、第9回の探索・見直し、第15回の対話と検査の限界 |

| 安全と実施体制 | 第12・14回で実習と引継ぎ | 第11回の体験・連携、第13回の学校を支える条件 |

## 工業の12群のミニ解説の配置

第2回で全体像と機械・電気電子・情報、第3回で材料・セラミック、第6回で化学、第7回で建築・建築設備・土木、第8回で繊維・インテリア、第11回でデザインを扱う。これはⅠの講義用の配置で、全国共通の学科分類ではない。補足は視聴中心にし、技術計算や技能の試験を課さない。各分野の細部は参照表に残す。
