# 職業指導の解説と演習を充実させる改訂案

> 全体見直し後の配置と到達目標は[現行の講義構成](syllabus.md)と各回の改訂設計を優先します。本ページの具体例・原稿・資料情報は、該当する回で使う補足です。

2026年11月4日。Ⅱでは、専門高校や職業の名称を知る学習に加え、中学校教師として情報を確かめ、生徒が選択肢を検討できるよう説明・相談する学習を充実させる。Ⅰの分野別補足は視聴中心とし、Ⅱでは短い演習から既存のレポート2本へつなぐ。以下は次の教材改訂案であり、公開中の動画へは未反映。

## 提示資料の位置付け

ご提示の[「職業指導 キャリアガイダンスについて 参考資料」](https://www.mext.go.jp/b_menu/shingi/chukyo/chukyo4/027/siryo/__icsFiles/afieldfile/2009/11/06/1286561_002_1.pdf)は、2009年11月5日の中央教育審議会大学分科会質保証システム部会第9回・資料2－2である。大学教育における履修指導、相談、情報提供、就職支援等の位置付けを検討する資料として読む。PDF2～3頁の、段階に応じた支援を教育活動全体で行う発想が本講義の検討に役立つ。

当時の大学の実施率、法令の引用、認証評価、外国制度は、現在の中学校・高校にそのまま適用しない。用語の整理も資料の作成年と対象を添えて扱う。中高の授業設計には、[文科省 2023年版 中学校・高等学校キャリア教育の手引き](https://www.mext.go.jp/a_menu/shotou/career/detail/mext_00010.html)第1章・第3章・第4章を併せて参照する。

具体的には第1章印刷13～17頁の、能力の枠組みを画一的に運用しないことと社会的・職業的自立の捉え方、第3章印刷58頁の、中学生期の探索や選択、個々の発達と学校の実態を踏まえる説明を確認した。講義の演習でも一つの尺度から進路を決める課題にはしない。

本案では、職業指導を単一の適職を判定する作業へ狭めず、学校での学び、仕事の情報、相談、選択、その後の学びをつなぐ指導として扱う。これは本講義の構成方針であり、2009年資料が中学生向けに示した指導法という意味ではない。

## Ⅱで育てたい具体的な力

- 産業、職業、実際の仕事の内容を分けて説明する。同じ産業にも多様な職業があり、同じ職業が複数の産業で働く場合もある。
- 学科名と職業を一対一で結ばず、学校での学びと、卒業後・その後の複数の経路を示す。
- 資格、免許、受験資格、養成課程、就職の条件を混同せず、未確認の条件を確認事項として残す。
- 関心を具体的な活動へ言い換える質問をつくる。適性や性格、家庭事情を、限られた記述から推定しない。
- 通学、学習、費用、働く条件や利用できる支援などを確かめ、教師だけで抱えず必要な相手につなぐ。
- 進路選択を一度きりの最終決定とせず、見直しや学び直しも含めて考える。

## 情報源の役割

| 情報源 | 講義で使う情報 | 読む際の注意 |
|---|---|---|
| [文科省 中高のキャリア教育の手引き](https://www.mext.go.jp/a_menu/shotou/career/detail/mext_00010.html) | 校種の役割、発達の捉え方、学校全体の取組 | 学年段階の例を個人へ一律に当てはめない。 |
| [厚労省 job tag](https://shigoto.mhlw.go.jp/User/) | 仕事の具体的な内容、入職経路、知識・技能、労働条件の特徴 | 数値の対象・年度を確認する。職業の説明と個別企業の募集条件は異なる。 |
| [job tag FAQ](https://shigoto.mhlw.go.jp/User/faq) Q2・Q4・Q5 | 職業情報・統計・学歴表示の読み方 | 統計の職業分類が掲載職業と一致するとは限らない。学歴表示を必要資格や入職要件と読まない。 |
| 学校・教育委員会の公式資料 | 教育課程、募集、見学、相談、進路実績 | 当該校・当該年度の情報。進路実績から全員の将来を断定しない。 |
| [厚労省 学校関係者向け就職支援情報](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyou/jakunen/teacher.html) | 学校と就職支援機関との連携を知る入口 | 中学校教師が高校の職業紹介業務をそのまま行うという説明にしない。 |
| [厚労省 労働法教育の指導者向け資料](https://roudouhou-kyouiku.mhlw.go.jp/kyosyokuinnokata.php) | 働く前に条件を確認し、困った際に相談する教材 | 法的な結論を事例の断片から断定せず、使用時の版と窓口を確認する。 |

job tagでは、自己診断・適性検査の受検や個人の結果の提出を課さず、職業解説の閲覧を基本にする。登録や個人情報の入力を授業参加の条件にしない。外部サイトへアクセスできない場合には、講義で用意した独自の資料カードで同じ学習ができるようにする。

## 課題と評価への反映

現行の[レポートA・Bとルーブリック](../assessment/README.md)の範囲で充実させる。Aは二つの学び・経路の比較、Bは複数の候補、関心を確かめる質問、条件・支援、次の確認・相談を扱っており、今回の焦点と対応する。提出数、目安字数、評価観点の追加はしない。

演習メモは提出不要とし、レポートへ再利用できるようにする。本人や家族の学校歴・職業・経験・経済事情は尋ねない。全員が、架空事例と人物を設定しない資料整理を理由の説明なしに選べる。教師のモデルと同じ学校・職業を選んだかではなく、根拠と説明の対応を現行基準で見る。

## 収録へ進む順序

まず第2回と第15回で、独自の資料カードと説明例を試す。第3回・第9回・第11回・第13～14回はその型に沿って改訂する。外部資料の本文・写真・動画を公開教材へ一括転載せず、出典と独自の説明を使う。参照範囲を絞り、学生に追加の広範な検索を義務付けない。
