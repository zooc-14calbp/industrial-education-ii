# 動画の実測時間と演習中心の授業設計

2026年11月4日。Ⅰ・Ⅱ各15回の動画初稿を作成し、再生時間を実測しました。初期案の「解説・読解70分＋活動20分」を固定せず、資料を根拠に考える演習を優先します。

各回に8枚の演習スライドと3ページの演習ガイドPDFを加えました。基本は「事実と未確認を分ける→説明案を点検する→説明を修正する」で、条件を変える発展課題は任意です。思考と修正のメモは提出せず、各科目2本のレポートへ再利用します。

以下の動画時間は実測値です。読解5～10分、既存のクイズ・メモ・休止、追加の基本演習等は計画上の目安で、学生による試用は未実施です。目安時間まで待つことや、90分を埋めるためだけの作業は求めません。基本演習を優先し、進度に応じて発展を選びます。

全動画の発音・抑揚の聴取と担当者による内容確認も、正式配信前の課題として残します。自動検査の通過を、授業全体の90分や学習効果の検証済みとは扱いません。
