# 専門高校の学びと資格や免許を説明する補足案

2026年11月4日。Ⅱ第3回で資格・免許・検定の見方を紹介し、第4～8回の分野紹介、第9回の経路、第15回の進路相談へつなぐ。Ⅰでは第2・7・14回の関連情報とする。以下は関連する代表例であり、全国の取得率を順位付けした一覧ではない。取得者の多さを説明する際は、学校・年度・対象人数等の実績を別に確かめる。

## 最初に区別すること

国家資格・免許と、各団体が行う民間検定を分ける。資格名だけで、できる業務の範囲、受験条件、合格後の手続、更新・講習の要否まで分かったことにはしない。「受験できる」「試験に合格した」「免状や免許証が交付された」「実際にその業務を行える」は分けて説明する。

学校で資格取得に向けて学習することと、全員が取得できることも異なる。学科の卒業だけで得られるのか、指定された養成課程・履修条件が必要か、別の試験や実務経験が要るかを確認する。資格数だけを、生徒の能力や学校教育全体の良し悪しの尺度にしない。

## 学校資料から確認する項目

「取得できる資格」という一覧に出会ったら、主催・交付機関、受験条件、試験合格後の手続、免除や指定課程の条件、学校内でどんな支援があるかを確かめる。実績を見る場合は、受験者数と合格者数、対象学年、延べ人数か実人数か、集計年度を区別する。全国の受験者の合格率と、ある学校の取得割合も同じではない。

資格の取得が必要な仕事と、必須ではないが学びの目安になる検定を分ける。資格があっても就職が自動的に決まるわけではなく、資格を取らない経路も含めて学校の学びと進路を説明する。

## 10分程度のThinking time

架空の案内文：「C校の電気系では第一種電気工事士試験の合格者がいます。卒業時に全員が第一種電気工事士免状を取得でき、電気関係の仕事は全て行えます。」

問い：試験合格、免状取得、業務の範囲の三点を分け、根拠が不足する箇所を直す。次に確認する公式資料と、学校へ尋ねる内容を一つずつ挙げる。個人の経験や実際の資格取得状況は書かなくてよい。

説明例：試験合格者がいることと、全員の免状取得は別である。第一種の免状取得には所定の実務経験等を確認し、業務の範囲も資格制度に照らして確かめる。学校の実績では、年度・受験者・合格者・免状取得者の区分を尋ねる。法的な手続の代行ではなく、情報を読み分ける演習とする。

独立した提出レポートは増やさず、Aの「解釈と限界」、Bの「条件と支援」「次の確認・相談」へ再利用する。
