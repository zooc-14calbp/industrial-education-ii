## 接続の基準となる資料

中学校では、情報活用能力を技術・家庭科だけに任せず、各教科等の特質を生かして育てる。操作の経験だけでなく、情報を得る、整理・比較する、発信・伝達する、保存・共有することと、情報モラル・セキュリティ等を関連付ける。[中学校総則解説](https://www.mext.go.jp/content/20251029-mxt_kyoiku01-100002608.pdf)第3章第2節2(1)、第3節1(3)。関連箇所をまとめた[教育の情報化に関する手引 巻末資料 中学校1頁](https://www.mext.go.jp/content/20200609-mxt_jogai01-000003284_004.pdf)も参照する。

技術分野「D 情報の技術」には、情報の技術の仕組み、ネットワークを利用した双方向性のあるコンテンツ、計測・制御のプログラミングによる問題解決等がある。[文科省の研修教材・事例集の入口](https://www.mext.go.jp/a_menu/shotou/zyouhou/technology/)

専門高校との対応では現行科目名を使う。工業は「工業情報数理」、水産は「海洋情報技術」を主な比較対象とする。「情報技術基礎」「工業数理基礎」等の旧科目名や、学校独自の科目名を見つけた際は、当時の指導要領・当該校の教育課程と照合する。共通教科「情報Ⅰ」と専門教科の科目も区別する。履修や代替の制度は、高校総則と各校の教育課程で別途確認し、科目名だけで同等と判断しない。

|---|---|---|
| 工業情報数理 | [工業編第2章第5節 印刷38～43頁 PDF48～53頁](https://www.mext.go.jp/content/20251203-mxt_kyoiku01-100002620_23.pdf#page=48) | 産業社会と情報技術、コンピュータシステム、プログラミングと工業に関する事象の数理処理。情報・数学・理科の学びを関連付ける。 |
| 海洋情報技術 | [水産編第2章第4節 印刷38～43頁](https://www.mext.go.jp/content/1407073_16_1_1_2.pdf) | 水産や海洋の情報技術、コミュニケーションと情報デザイン、コンピュータとプログラミング、ネットワークとデータの利用、分野への応用。 |

高校で学ぶ専門的な内容を全て中学校で先取りさせる案にはしない。以下は両校種の内容を踏まえた本講義の接続案であり、全国共通の追加到達基準ではない。

## 中学校側で整える学習と引継ぎ

| 中学校で繰り返し使う学習 | 高校の初期学習との接続例 | 中学校でできる対応 |
|---|---|---|
| ファイルの保存・名称・整理、共有範囲の確認 | 実験記録、図面、プログラム、報告書の管理 | 特定のアプリだけに依存せず、保存場所、形式、版の違い、共有先を言葉で説明する。 |
| 出所・日付・単位を付けて記録する | 工業の測定記録、水産の水温等の記録 | 理科や数学等の表でも、何をいつどう測ったか、欠測や単位を明示する。 |
| 表・グラフを作り、意味を説明する | 数理処理、海洋・生産等のデータ利用 | グラフ作成だけで終えず、軸、単位、母数、比較条件と、言えないことを説明する。 |
| 情報を検索し、複数資料と照合する | 技術・産業情報、気象・海況や流通等の情報 | 上位表示だけで決めず、作成者・年度・対象・根拠を確かめる活動を入れる。 |
| 条件と処理手順を整理し、結果を検証する | 工業のアルゴリズム・制御、水産の情報処理 | 技術分野等で、入力・処理・出力、予想と実行結果、修正理由を説明する。 |
| 個人情報、著作権、安全な共有を考える | 実習写真、位置情報、共同制作物、ネットワーク利用 | 何を公開し、何を控え、誰に相談するかを具体例で繰り返す。 |
| 図・表・文章を組み合わせて説明する | 実習報告、設計提案、共同作業 | 見た目の装飾より、相手が根拠と手順を読み取れる表現を重視する。 |

技術科、理科、数学、国語、社会、総合的な学習の時間等で役割を分担する。一つの教科へ全てを追加しない。端末利用時間や入力速度だけを、情報活用能力の十分な指標としない。

引継ぎでは、必要な同意や学校の取扱いに従い、経験した活動、使った表現や形式、既に行って効果があった支援を伝える。アカウントのパスワードや生徒の個人データを無条件で共有する案にはしない。高校側も短い導入課題等で既習事項を確かめ、機器・ソフト・用語の違いを補う。接続の責任を中学校や生徒だけに置かない。

## Thinking timeの課題案

架空の学習記録：ある中学校では、理科で毎日の水温を表にし、数学でグラフを作り、技術でセンサーによる計測・制御を学んだ。高校側の導入課題では、測定記録を保存し、表やグラフで説明する活動を予定している。利用するアプリと機器は中学校と異なる。この設定は講義独自の例である。

10～15分程度を目安に、次の三点を短い表へ整理する。

1. 既に経験したことを、アプリ名ではなく活動や理解の言葉で二つ示す。
2. 中学校で次に加える工夫と、高校側で確認・補足することを一つずつ示す。
3. 工業と水産の双方へつながる点と、専門高校で新たに学ぶ内容を一つずつ分ける。

説明例：表の各列に測定日・単位・測定条件を残す活動は、工業・水産の双方のデータ利用へつながる。高校では、別のソフトで読み込めるか、グラフから何を説明できるかを導入で確かめる。水産や工業の専門装置、実際の業務上の判断まで中学校で習得済みとはみなさない。

実物のプログラムや高度な表計算は提出させない。メモはレポートBの「条件と支援」「次の確認・相談」に利用できる。本人のICT経験や苦手さの申告は求めない。

## 第10回の構成への組込み

従来の「読む・数量や図表を扱う」という接続例の一部を、このICTの事例へ組み替える。全国学力・学習状況調査の対象と限界の説明は残し、その結果を高校生のICT能力の測定値として扱わない。解説と事例の紹介に8～12分、上のThinking timeに10～15分を仮置きし、既存演習との重複を減らして調整する。いずれも実測前の目安である。
