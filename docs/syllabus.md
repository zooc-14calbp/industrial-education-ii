# 工業科教育論Ⅱ 授業構成案

後期90分×15回。検討段階の構成です。

| 回 | タイトル | 到達目標 |
|---|---|---|
| 1 | 中学校卒業後の多様な学びと進路 | 高校の学びの違いと、中学校教師がそれを知る意義を説明できる。 |
| 2 | 社会を支える産業と仕事の多様性 | 身近な製品やサービスに関わる産業・職業のつながりを説明できる。 |
| 3 | 専門高校の種類と学校情報の読み方 | 学校案内や教育課程表から学習内容・実習・進路の特徴を読み取れる。 |
| 4 | 工業高校の学びとキャリア | 専門分野と授業・実習を関連する仕事や進学先と結びつけて説明できる。 |
| 5 | 農業・食品・森林・環境を学ぶ高校 | 学校事例から生産・加工・地域資源に関わる学びと進路を説明できる。 |
| 6 | 水産・海洋を学ぶ高校 | 学校事例から水産・海洋分野の学習内容と進路を説明できる。 |
| 7 | 商業・ビジネス・情報を学ぶ高校 | 学習内容を商品・サービス・情報を扱う仕事に結びつけて説明できる。 |
| 8 | 家庭・看護・福祉などを学ぶ高校 | 学習内容と資格取得・就業・進学の経路の特徴を読み取れる。 |
| 9 | 専門高校生のキャリアパスと学びの継続 | 就職・進学、その後の転職・学び直しなど複数の経路を説明できる。 |
| 10 | 小中高の学びの接続と中学校の役割 | 中学校の学習が専門高校の学びにつながる具体例を示せる。 |
| 11 | 職場体験・インターンシップ・地域との連携 | 中高の活動の目的や違いを捉え、必要な事前・事後指導を挙げられる。 |
| 12 | 国内外の職業教育と学校・企業の役割 | 共通の観点で学校と企業の役割や学習経路の違いを比較できる。 |
| 13 | 高校での学習上の困難と中途退学・進路変更 | 複数の事情を踏まえ、事例に即した支援や中高間の連携を考えられる。 |
| 14 | 高校に進学しない若者と学び・就業への支援 | 状況を一括りにせず確認すべき情報や支援先を挙げられる。 |
| 15 | 生徒の選択肢を広げる進路指導 | 生徒の関心や事情から複数の選択肢と確認・相談事項を示せる。 |
