# 工業科教育論Ⅱ 授業構成案

後期90分×15回。検討段階の構成です。

| 回 | タイトル | 到達目標 |
|---|---|---|
| 1 | 中学校卒業後の多様な学びと進路 | 高校の学びの違いと、中学校教師がそれを知る意義を説明できる。 |
| 2 | 社会を支える産業と仕事の多様性 | 身近な製品やサービスに関わる産業・職業のつながりを説明できる。 |
| 3 | 専門高校の種類と学校情報の読み方 | 学校案内や教育課程表から学習内容・実習・進路の特徴を読み取れる。 |
| 4 | 工業高校の学びとキャリア | 専門分野と授業・実習を関連する仕事や進学先と結びつけて説明できる。 |
| 5 | 農業・食品・森林・環境を学ぶ高校 | 学校事例から生産・加工・地域資源に関わる学びと進路を説明できる。 |
| 6 | 水産・海洋を学ぶ高校 | 学校事例から水産・海洋分野の学習内容と進路を説明できる。 |
| 7 | 商業・ビジネス・情報を学ぶ高校 | 学習内容を商品・サービス・情報を扱う仕事に結びつけて説明できる。 |
| 8 | 家庭・看護・福祉などを学ぶ高校 | 学習内容と資格取得・就業・進学の経路の特徴を読み取れる。 |
| 9 | 専門高校生のキャリアパスと学びの継続 | 就職・進学、その後の転職・学び直しなど複数の経路を説明できる。 |
| 10 | 小中高の学びの接続と基礎学力 | 全国学力・学習状況調査の対象と限界を理解し、中学校の学びが専門高校につながる具体例と接続を支える工夫を示せる。 |
| 11 | 職場体験・インターンシップ・地域との連携 | 中高の活動の目的や違いを捉え、必要な事前・事後指導を挙げられる。 |
| 12 | 国内外の職業教育と学校・企業の役割 | 共通の観点で学校と企業の役割や学習経路の違いを比較できる。 |
| 13 | 高校での学びの継続と多様な進路への支援 | 普通科・専門学科に共通する課題と違いを踏まえ、架空事例から学びの継続・進路変更を支える方法と学校・教員を支える条件を考えられる。 |
| 14 | 高校に進学しない若者と学び・就業への支援 | 状況を一括りにせず確認すべき情報や支援先を挙げられる。 |
| 15 | 生徒の選択肢を広げる進路指導 | 生徒の関心や事情から複数の選択肢と確認・相談事項を示せる。 |

## 学力と中高接続の位置付け

第10回では、読む・説明する・数量や図表を扱う学びが、専門高校の実習、報告書、測定・製図などにどうつながるかを具体例で考えます。[文部科学省の全国学力・学習状況調査](https://www.mext.go.jp/a_menu/shotou/gakuryoku-chousa/)を用い、教科の結果と学習状況の質問調査を区別します。[調査概要](https://www.mext.go.jp/a_menu/shotou/gakuryoku-chousa/zenkoku/1344101.htm)に示される対象は小学校6年生・中学校3年生です。工業高校生の学力を直接測ったものとは扱わず、工業基礎学力テストとの得点の直接比較もしません。質問調査で見られる関連だけから、家庭事情や学習習慣を学力差の原因と断定しません。

第3回では学校情報の確認、第4回では工業高校の学びと進路の背景として、[工大サミット基調講演「全国の工業高等学校の現状と課題」](https://www.kait.jp/summit/program/pdf/program1.pdf)も参照します。Ⅰで学んだ専門科目の指導を踏まえ、Ⅱでは中学校教師が生徒の選択肢を広げるための情報提供と相談に重点を置きます。

## 学びの継続と多様な進路への支援

第13回は全員が学ぶ共通回とし、学びの継続と多様な進路への支援の中で、中途退学も重要な論点として扱います。学習のつまずき、欠席・不登校、学校や進路との不一致、人間関係、心身の状態、家庭・経済事情などを事例から検討します。これらは検討の観点であり、個別事例の原因を統計の一分類や成績だけで断定しません。工業高校だけの問題とせず、普通科・専門学科、全日制・定時制・通信制の違いや、調査の対象範囲も確認します。

[文部科学省「児童生徒の問題行動・不登校等生徒指導上の諸課題に関する調査」](https://www.mext.go.jp/a_menu/shotou/seitoshidou/1302902.htm)の中途退学に関する集計と定義を参照します。人数・率・分母・年度を確認し、転学、退学後の編入、不登校、高校非進学を区別します。公表される「主な理由」を、生徒の事情の全てを示すものとは解釈しません。

在学中の学習・相談支援、学校内外の連携、転入・編入や定時制・通信制などへの学習経路の変更、退学後の学び直し・就業支援を扱い、第14回の高校非進学者への支援とつなぎます。高等学校卒業程度認定試験の合格と高校卒業も区別します。制度の要件や窓口は教材制作時に公的資料で確認します。中学校教師の役割として、学校の学習内容を具体的に伝える進路相談と、必要な情報を適切に引き継ぐ連携を考えます。

教材70分・確認活動と小休止20分、全15回、科目全体で提出レポート2本程度を維持します。第13回では短い架空事例に対し、追加で確認したい情報と相談・支援先を一つずつ挙げる活動を設け、独立した提出レポートにはしません。

## 第13回の教材と活動への配慮

受講者の学校歴、不登校・退学、高校卒業程度認定試験や旧大学入学資格検定などの経験の申告は求めません。経歴によって受講内容を振り分けず、当事者が受講していることを前提に設計します。当事者に代表として説明や体験談の提供を求めません。

事前の学習案内に、中途退学・不登校・進路変更を含むことと、本人の経験を書く必要がないことを示します。架空事例は、学習のつまずき、進路や学び方との不一致、学校生活・生活条件などを扱う複数のものを用意し、全員が選べる形にします。いずれも必要な情報と支援を考える共通の到達目標とし、本人の経験の開示は評価対象にしません。特定事例への取り組みが難しい場合は、個人の事情の説明を要しない制度・支援情報の整理でも同じ目標を確認できるようにします。

普通科も含む高校教育全体の課題として、高い高校進学率の下で多様な学習歴・関心・生活条件をもつ生徒を受け止める教育課程、履修・卒業の仕組み、相談・学習支援体制を検討します。進学率の高さだけから中途退学や教員負担の原因を断定せず、教育機会の保障と、実際に学び続けられる条件の両方を考えます。

工業科教員については、専門科目・実習の指導、安全管理、設備や材料の管理と、生徒への学習・生活支援を併せて担う状況を検討します。個々の教員の努力に解決を委ねず、教員間の分担、学校内外の専門職との連携、支援に使える人員・時間・資源も論点とします。これらの負担の程度や原因は、教材制作時に根拠資料や具体例を確認します。
