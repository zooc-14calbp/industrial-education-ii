# 90分に向けた内容の充実と推敲

2026年11月4日。Ⅰ・Ⅱ各15回に共通する改訂方針です。

各回は、解説・図解・具体例・指定資料の読解70分、クイズ・短いメモ等15分、小休止5分の計90分を目標とします。計画上の時間と実際に確認した時間を区別します。現時点では全30回の90分確認は完了していません。

## 内容を補う順序

1. 各回の到達目標に照らして、初学者に必要な用語、背景、資料の読み方を補います。
2. 解説と対応する図・比較表・具体例を加え、考え方の手順と確認例を示します。思考活動の時間を解説時間へ重複計上しません。
3. 指定資料の範囲、読む目的、読み取り例を示します。単に読む時間を長く指定して不足を埋めません。
4. 解説原稿・音声と読解の試用時間を記録し、70分の内訳を調整します。動画はNanami（Natural）を用い、発音・速度・字幕を確認します。
5. スライドと学生用ガイドの対応、文字量・配色・図表の見やすさを確認します。

まず、動画試作から約22分の補充が必要と分かったⅡ第1回と、具体例・解説の不足が見られるⅠ第9～15回を重点的に推敲します。他の回も全文原稿と試用により点検します。詳しくは[時間点検](duration-audit.md)を参照してください。

## 学生の負担と課題

内容を増やす際も提出レポートは各科目2本とし、毎回のクイズ・メモは提出しません。既出資料とメモをレポートに再利用できます。授業外で行う最終的なレポート作成を、各回の90分に重ねて計上しません。課題と基準は[レポート課題と評価基準](../assessment/README.md)に示します。

本人や家族の経験・学校歴の開示は求めません。全員が架空事例または公開情報の分析を選べる構成を維持します。
