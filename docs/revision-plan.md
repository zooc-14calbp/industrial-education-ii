# 講義全体の見直しと教材改訂の進め方

2026年11月4日。現行の改訂基準は[全15回の構成](syllabus.md)と[全体見直し](overall-review.md)である。70分の解説動画を作るために内容を増やす方針から、理解すべき前提知識、専門の具体例、主たるThinking timeを整える方針へ改めた。

## 各回の制作でそろえるもの

到達目標は二つまでを目安に絞り、内容の柱三つ、指定資料の箇所、主たる問い一つ、説明例と短い自己確認、レポートへの接続を用意する。専門分野や制度を知る説明には、必答問題を一律に付けない。資料確認と考える時間を二重に数えない。

図や例は目標と役割を先に決め、聞くだけでも専門高校の授業を想像できるものを加える。長い外部動画や大量の学校資料をそのまま追加しない。AIは固定の模擬資料でも学べるようにし、学生による登録・契約は不要とする。

## 差替の優先順

1. 個人の高校生活を尋ねるⅠ第3回の問いと、古い70＋20分等の表示を、現行の学修案内にそろえる。
2. Ⅰ第7回の専門科目、Ⅰ第11回の教材・AI、Ⅱ第2回の社会の基礎、Ⅱ第3回の資格、第9回の統計・働く条件、第10回のICT接続、第15回の相談を改訂する。
3. 各分野の紹介とミニ解説、復習の問い、回の間の接続をそろえる。
4. スライドPPTX・PDF、ガイドPDF、音声・字幕・動画の内容を対応させ、実測時間と更新箇所を記録する。

## 維持する条件

一回90分程度は動画・資料・Thinking time・小休止を含む目安とする。提出レポートは各科目2本、毎回のメモは提出不要、個人史の開示不要という条件を維持する。評価観点の追加や、高度な製作・模擬授業の必修化はしない。

## 今回の到達点

全30回の設計の見直しと各回の差替内容の整理を完了した。現行動画・スライドの全差替は未実施である。新しい内容の原文確認や一部の資格・制度等の詳細確認、担当者の内容・発音確認、学修時間の試用は制作と併せて進める。
