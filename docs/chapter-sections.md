# 工業科教育論Ⅱ：15章の節構成

2026年11月6日。**第1回～第15回を第1章～第15章**とします。各節は、工業高校を高校教育全体の中で理解し、中学校からの進路相談につなぐための話題のまとまりです。章題から現在の本文へ進めます。スライド・ガイド・動画への節番号の表示は、各回の内容改訂時に順次反映します。
