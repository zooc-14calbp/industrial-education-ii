# 工業科教育論Ⅰ・Ⅱ 全30回の授業時間点検

点検日：2026年11月4日。判定対象は現在保存されている教材と動画。法令・統計の再調査や新たな収録は行わず、教材の分量と時間の根拠を点検した。

## 結論

**現在の教材を、全30回とも90分程度のコンテンツとして構築済みとは判定できない。** 全30回で「解説・指定資料読解70分＋クイズ・メモ・小休止20分」という計画値の合計は一致する。しかし、時間を割り当てたことと、その時間を支える解説・資料・問い・解説例が実装されたことは別である。

実際の動画があるⅡ第1回は、動画38分07秒に、原稿中で案内する読解約10分と、クイズ・メモ・休止20分を加えると**約68分07秒**。90分との差は**約21分53秒**である。後二者は予定時間で、受講者の実測ではない。動画の中には活動の説明も含むため、この合算も厳密な実測学習時間とは扱わない。現時点で90分を裏付ける追加の学習場面は明示されていない。

残る29回には、このⅡ第1回のような完成した読み上げ原稿・合成音声・動画がない。各回の実時間は未測定で、何分不足するかは確定できない。既存のノートをそのまま読むだけで70分になる内容ではなく、図や資料を使う具体的な解説、事例を比較する説明、読解後の解説を補う必要がある。

全30回の判定は「90分充足の確認済み0回」「案内された時間を積算すると90分に届かない試作1回」「実時間未測定・構築途中29回」。これは29回全てを実測して短いと断定したものではない。

## 時間の割当を再検討する根拠

Ⅰ第9～15回は各24枚。資料・考え方25分と事例・改善25分という同じ枠を使用し、事例を検討するスライドに6.25分などを割り当てている。例えばⅠ第11回のスライド15は「材料を選ぶ授業で写真だけを配った」という短い設定と問いが中心で、比較用の材料情報等がまだ十分に用意されていない。第13回のAI評価を点検する場面も、実際に照合する架空答案とAI案を補う必要がある。これらを長い思考時間と解釈して、別途設けた20分の活動枠と重複計上してはならない。

Ⅰ第11回スライド15の本文は材料選択、ノートは手順書の点検の説明が中心であり、第13回の同じスライドも本文はAIの根拠誤引用、ノートは完成品の評価の説明になっている。長い説明原稿へ展開する前に、題材と解説の対応をそろえる必要がある。

Ⅱ第3～15回は各28枚で、前半22分・後半25分の枠を各場面へほぼ均等に配分している。例えば第3回では、学科別人数表の注記や、教育課程表の指定列の短い読解を4分前後とし、要約・解説にも同様の時間を割り当てる。これは設計上の割当で、既に4分の説明が用意されたことを意味しない。関連するスライドで同じ説明を繰り返している箇所も整理する。

Ⅰ第5回は法的根拠・本文・解説の対応が比較的具体化され、第10回にも公刊実践の指定箇所がある。ただし、分量が多い原資料へのリンクがあるだけで、その全文の読解時間を授業に計上しない。指定範囲、読む目的、解説との関係、所要時間を対応させる。Ⅰ第5回の法令読解、第10回の論文読解、Ⅱ第12回の海外資料などは、初学者の読む速さや用語の負担によって時間が長くなる可能性もある。未測定の回へ一律に22分を追加せず、説明の不足と読解の負担を別々に測り、多すぎる場合は範囲を絞る。Ⅱ第11回の「指定部分」などはページ・小見出しの確定が先に必要である。

Ⅱ第13・14回の内容を厚くするときも、受講者本人の経験の説明や、詳しい生活事情の記述を追加しない。架空事例または公開情報の整理を全員が理由なしで選べる設計を維持する。

## 90分程度へ整える際の共通案

元の「提供する解説・資料70分、残り20分」という方針を維持し、例えば次のように実装する。これは今後の制作上の目安で、全回の実測済み内訳ではない。

| 要素 | 時間案 | 用意するもの |
|---|---:|---|
| 図解・具体例・資料を読む実演を含む解説動画 | 55～60分 | 実際に発話する原稿、図表、読み解きの手順、説明例 |
| 範囲を絞った資料読解 | 動画と合わせて70分になる10～15分 | 資料名・ページや見出し・読む目的・照合先を指定 |
| クイズ・短いメモ | 計15分 | 既定の3分＋5分＋7分。毎回の提出にはしない |
| 小休止 | 計5分 | 既定の2分＋3分 |
| 合計 | 約90分 | 動画・読解・活動を重ねて数えない |

例として「動画60分＋読解10分＋クイズ・メモ15分＋休止5分＝90分」、または「動画55分＋読解15分＋クイズ・メモ15分＋休止5分＝90分」とする。長い無音、同じ話の繰り返し、資料の全文読破、提出課題の増加で時間を埋めない。学ぶ目標に必要な説明と例を追加してから、音声を生成し所要時間を積み直す。理解する速さに個人差があるため、90分ぴったりを全員へ要求する設計にはしない。

Ⅱ第1回を後者でなく「動画60＋読解10」の形へ整えるなら、動画の追加は約21分53秒になる。例えば制度比較の図解6分、学校資料を読み解く教師の実演8分、相談での説明案の修正例8分という追加が候補になる。この22分は学生への追加の提出課題にしない。これらの追加動画は本点検時点では未制作。

## 次の制作順序と確認基準

1. Ⅱ第1回で、実時間と教材・活動の対応を先に確立する。38分の試作をそのまま他の29回の標準としない。
2. Ⅰ第5回などの資料読解がある回と、Ⅰ第11・13回など教材補充が必要な回で、それぞれ原稿・教材を作り実測する。
3. その結果を使い全30回へ展開する。各回に動画の実再生時間、読解の指定範囲と時間案、活動・休止、合計、未確認事項を記録する。
4. 初学者相当の試用で、説明を止めて読む時間を含む全体の所要時間と負担を確かめる。未測定の時間を実測値と混在させない。

科目全体の提出レポート2本は維持する。最終レポートの授業外の執筆時間を、無条件に第9回・第15回や他の回の90分へ上乗せしない。授業中に既定のメモを再利用する時間と、別途の提出作業を区別する。

この点検では、スライド・音声・課題そのものは変更していない。全30回の時間設計の不足を特定し、制作状況に「計画」と「実時間の未確認」を明示する点検資料を追加した。
