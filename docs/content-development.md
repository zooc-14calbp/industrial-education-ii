# 講義本文の充実を優先する進め方

2026年11月5日。Ⅰ・Ⅱとも、当面は講義の説明内容を充実させます。動画の収録、スライドの体裁やPDFの更新は、本文を検討した後に行います。以前の試作教材と、今回の文章による改訂を区別します。

本文は、学生へ説明する内容の元原稿です。全てを追加の必読資料として配る計画ではありません。特に専門分野の紹介は、説明を聞いて理解する部分を保ち、課題の増加へ置き換えません。

## 説明を増やす部分

初めて専門高校や産業の制度を知る受講者にも分かるよう、用語を使う前に意味を説明します。身近な具体例を示し、その例のどの部分が科目・制度・統計と関係するかを文章でつなぎます。定義や科目名の一覧だけで説明を終えません。

説明の途中では、混同しやすい概念を分けます。例えば、学科と科目、単位と授業時数、産業と職業、学位と教員免許、数値とその解釈です。架空例は架空と示し、実在の教育課程や統計には対象年度・区分・参照箇所を添えます。

一つの題材を複数の段階で使い、事実、そこからいえること、追加確認が必要なことを順に説明します。説明の量は増やしますが、同じ注意書きの反復や用語の列挙で長くしません。詳しい計算、資格要件の一覧、全分野の網羅等は、理解に必要な範囲を選びます。

## 学習負担と時間

各回の中心となる問いは一つ、提出レポートは各科目2本を維持します。途中の例や短い問いは、その理解を支えるために使います。毎回の提出、個人の経験の開示、現地調査、AIへの登録等は追加しません。

90分程度の学修は、説明、指定資料の確認、Thinking time、休止を組み合わせて考えます。本文の文字数を授業時間と同一視せず、以前の解説25～35分等の仮置きも確定値として扱いません。内容の検討後に配分を見直し、後の収録時に動画の実測時間を分けて示します。
