# 社会と仕事を理解するための基礎事項

> 全体見直し後の配置と到達目標は[現行の講義構成](syllabus.md)と各回の改訂設計を優先します。本ページの具体例・原稿・資料情報は、該当する回で使う補足です。

2026年11月4日。Ⅱ第2回を入口に、産業、職業、雇用、学習経路、基本的な制度を具体例から確かめる。既知であることを前提にせず、用語を説明してから資料や相談場面を扱う。受講生の知識不足を測る試験にはしない。現行動画への組込み前の改訂案である。

## 第2回の導入

| 基礎事項 | 最初に伝えること | つなげる話題 |
|---|---|---|
| 第一次産業 | 農業・林業・漁業など、自然の資源を得る活動 | 農業・水産の学びと、加工・物流・販売との関係。 |
| 第二次産業 | 鉱業、建設業、製造業など | 工業高校の学びが、製造業以外にも関わること。 |
| 第三次産業 | 商業、運輸、情報通信、医療・福祉、教育等の多様な活動 | 「サービス業」という一語で仕事を同一視しない。 |
| 産業と職業 | 産業は勤め先等の事業内容、職業は本人が担う仕事の内容に着目する分類 | 製造業の事業所にも設計・生産・経理・営業などがあり、同じ職業が異なる産業で働く例がある。 |
| 就業者と雇用者 | 自営業主や家族従業者を含む「就業者」と「雇用者」を区別する | 「働く人」を全員会社員として説明しない。 |
| 構成比 | 何を全体とした割合かを必ず示す | 就業者数の比率と、GDP・生産額の比率は異なる。 |

三部門は大きな見取り図であり、細かな産業分類の代わりではない。本教材の集約では、農林漁業を第一次、鉱業・建設・製造を第二次、それ以外の分類可能な産業を第三次にまとめる。電気・ガス・熱供給・水道業はこの集約の第三次に含める。

## 就業者の構成比を読む例

[総務省統計局 日本の統計2026 第19章](https://www.stat.go.jp/data/nihon/19.html)表19－3・19－5の令和6年（2024年）平均の就業者数を用いる。刊行年の2026年と、データの2024年を区別する。以下は表19－5の丸められた数値を講義で合算し、総数6,781万人を分母に算出した参考値で、三部門の公式表をそのまま転載した値ではない。

| 講義での集約 | 就業者数の合算 万人 | 総数に対する割合 概算 |
|---|---:|---:|
| 第一次産業 | 192 | 2.8％ |
| 第二次産業 | 1,525 | 22.5％ |
| 第三次産業 | 4,944 | 72.9％ |
| 分類不能の産業 | 122 | 1.8％ |

元の値は万人単位に丸められており、内訳の合計6,783万人は総数と2万人異なる。数値を勝手に修正せず、この差を注記する。構成比も概数として扱う。[抜粋と集約の計算記録](industry-sectors.json)、[産業別の元数値CSV](industry-employment.csv)、[グラフ演習PDF](statistics-exercise.pdf)を参照。

割合の小ささは産業の重要性の小ささを意味しない。農林水産物、エネルギー、建物、物流等は互いに支え合っている。全国の比率を、地域の就職先の比率や個々の生徒の進路にそのまま当てはめない。

## Ⅱ全体で補う基礎事項

| 回 | 基礎事項 | 教師としての使いどころ |
|---|---|---|
| 第1・3回 | 高校の学科・課程、専修学校、高専、職業能力開発施設、専攻科等の違い | 学校名の印象だけで進路を説明しない。 |
| 第2・4～9回 | 産業・職業・働き方、資格・免許・検定、卒業時とその後の経路 | 仕事と学びを複数の観点で結び付ける。 |
| 第10回 | 情報活用能力、データの出所・単位・グラフの読解 | 中学校で学ぶ力と、専門高校の導入をつなぐ。 |
| 第11回 | 職場体験と就業体験、学校と受入先の役割、安全と事前・事後指導 | 見学で知った範囲と、まだ分からない仕事を区別する。 |
| 第12回 | 学校・企業・行政の役割、制度の比較条件 | 海外の制度名だけで日本へ当てはめない。 |
| 第13～15回 | 学び続ける条件、学び直し、働く条件、相談窓口 | 選択肢を示すことと、必要な支援へつなぐことを組み合わせる。 |

法律・制度は、場面、保護される権利や目的、誰が何を担うか、確認先をセットで示す。Ⅰ第5回の教育法規の位置付けと関連付けつつ、Ⅱでは進学・就業・体験・資格・相談に必要な基礎へ重点を置く。金額・年齢・申請条件など変わり得る情報は、教材採用時の公的案内で確認する。

労働条件の導入には[厚労省の労働法教育資料](https://roudouhou-kyouiku.mhlw.go.jp/kyosyokuinnokata.php)を参照する。具体的なトラブルの法的結論を本講義で即断させず、「何の条件を、どの資料や窓口で確かめるか」を課題にする。

各回で基礎事項を一～二点取り上げて再使用し、用語を大量に暗記させない。職業指導の[演習](career-guidance-exercises.md)、[資格・免許の整理](qualifications-plan.md)、[統計の読み方](statistics-reading.md)へつなげる。
