## 今回の確認

第3～15回の最終PPTX全364枚を画像にして個別に確認した。構造・配置検査では全13ファイルに指摘なし。PowerPointからPDFを出力し、全364ページの各テキスト要素がPDFに存在することを照合し、各回の表のページも目視確認した。学生用39ページ・担当者用26ページと共通評価資料4ページを全ページ目視確認した。資料の日付と対象、事実と授業用の解釈を区別した。これは授業の効果や70分の実時間を検証したものではない。

## 2周目に行うこと

- 担当者が全体の重複・難易度を確認し、数回を試用して指定資料読解を含む所要時間を測る。現在のノートは説明要点で、完全な読み上げ原稿ではない。
- 第11回の手引き読解を、配信時に使う版のページ・小見出しまで具体化する。リンク切れや接続できない資料は独自要約で代替できるようにする。
- 図・写真・短い動画の必要箇所を選び、権利と説明上の効果を確認して追加する。現段階の図表は編集可能な図形と表を中心とする。
- 第10回の学力と第13回の学びの継続は、受講者を分類する説明になっていないか再読する。中途退学の実数・率を追加する場合は、年度・対象・分母・調査上の理由を一組で示す。現初稿では中退の数値比較は行っていない。
- 統計、学校の募集・教育課程、資格や支援の要件を実施年度に更新する。2025年全国統計と2026年一校の実績を混同しない。免許を取得可能な大学の数は本初稿では集計していない。
- 2本のレポートの締切、総合成績への換算、再提出、評価に関する問い合わせ方法を確定し、架空答案で採点者とAI評価案の基準の一致を確認する。
- 動画を収録し、字幕・音声・画面の読みやすさを確認する。実際の答案をAIで処理する運用は大学の情報管理・利用規程に適合する環境と案内を整えてから検討する。

学校や国の優劣、学科と職業の一対一対応、経歴に基づく能力の推定を避ける。全員が個人史の説明なしに公開情報の整理を選べる設計を維持する。
