# 参考シラバスと本講義への取込み

2026年11月4日。日本大学の次の公開シラバスを、職業指導の内容の点検に用いた。いずれも科目名は「工業職業指導Ⅰ」であり、本講義の工業科教育論Ⅰ・Ⅱの全体を置き換える基準ではない。

- [2019年 理工学部 工業職業指導Ⅰ](https://www.kyoumu.cst.nihon-u.ac.jp/syllabus/Publication/2019/course/1/E46M/5190)
- [2025年 理工学部 工業職業指導Ⅰ](https://www.kyoumu.cst.nihon-u.ac.jp/syllabus/Publication/2025/course/1/E65A/5122)

両例から、法的な位置付け、就労環境の資料、発達を踏まえた指導、国際的な比較、体験活動、相談の考え方という柱を点検した。2025年例のAIと産業・社会の変化、検査の取扱いという話題も、Ⅱの見直しへ関連付けた。

本講義では、Ⅰ第5回に法と教育課程、Ⅱ第1回に職業指導の意味、第2・9回に社会・就労の基礎と統計、第10・11回に接続と体験、第12回に制度比較、第15回に相談とAI・検査の限界を配置する。年齢段階や検査を、生徒を一律に分類して進路を決定するために用いない。

参考シラバスの対面方式、予復習時間、模擬授業、出席や課題の配点は、本講義の条件へそのまま移さない。本講義はオンデマンド、毎回のメモは提出不要、レポート2本、個人史の開示不要という設計である。参照先の課題文は、受講生への指示として採用しない。

2019年・2025年当時の授業計画であり、法令・統計・AI等の現状を直接裏付ける資料としては使わない。制度と内容の確認には、[学習指導要領と解説](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)、[2023年版キャリア教育の手引き](https://www.mext.go.jp/a_menu/shotou/career/detail/mext_00010.html)、[文科省の学校現場の生成AI資料](https://www.mext.go.jp/zyoukatsu/ai/)等の一次情報を使う。
