# 学修の進め方

工業科教育論Ⅱは、動画視聴・資料の確認・考える時間・小休止を含め、1回90分程度を目安に学修します。動画自体を90分にする必要はなく、「70分＋20分」も固定の配分ではありません。時間を埋めるための説明や課題は加えず、到達目標の理解と受講生の負担を基準に調整します。

## 一回の学修

1. 各回の利用案内で、到達目標、動画の実測時間、資料、考える時間の場所を確認します。
2. 動画を視聴し、図表や資料を見るとき、問いについて考えるときに一時停止します。
3. 問いでは、資料の根拠を探す、比べる、別の説明を考える、例と比べて修正する、という活動を行います。頭の中で考えるだけでなく、一言のメモや短い表も使えます。
4. 演習ガイドの説明例で振り返り、必要な箇所へ戻ります。小休止も取り入れます。

考える時間も授業の一部です。動画を最後まで再生することだけで一回の学修が完了するという意味ではありません。一方で、考え終わった後に時間を埋めるためだけに待つ必要はありません。

各回には、説明を聞いて理解を広げる部分と、自分で資料を使って考える部分があります。全ての説明に解答や提出を付ける構成にはしません。基本の問いを優先し、任意の発展は進度に応じて選びます。資料読解と演習が重なる時間は二重に数えません。

## メモとレポート

毎回のメモ・クイズは提出不要です。成績評価のために提出するのは、科目全体のレポートA・Bの2本です。授業内のメモを再利用できます。[課題と評価基準](../assessment/README.md)を参照してください。

本人や家族の学校歴・仕事・経験・経済事情を書く必要はありません。架空事例と、人物を設定しない資料の整理を、理由を説明せず選べます。

## ウェブ資料と時間の目安

リンク先のサイト全体や外部動画の全編を、追加で学修することは求めません。指定箇所を確認し、閲覧できないときには授業の独自資料と説明で取り組めるようにします。

動画時間は実測値ですが、読解・考える時間は計画上の目安です。学修に要する時間には幅があります。現在の教材は検討用初稿で、学生による所要時間の試用を経て調整します。[各回の動画・演習](../video/README.md)と[実測時間と授業設計](video-duration-current.md)を確認してください。

資料の一部にある「70分＋20分」は初期案の時間配分です。現在の進め方は、この案内と各回の利用案内に従います。
