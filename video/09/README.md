## 時間と進め方

動画視聴・資料の確認・Thinking time（考える時間）・小休止を含め、1回90分程度を目安に学修します。動画の再生時間を一律70分にそろえる構成ではありません。 [共通の学修案内](../../docs/study-guide.md)も参照してください。

動画の再生時間は **25:13（実測）**。資料の確認は5～10分程度、既存のメモ・クイズは15分程度、小休止は5分程度が目安です。動画中で既に案内している資料読解も、この5～10分に含み、重ねて加算しません。

追加の基本演習1～3は合計24～30分程度。演習4は任意の発展課題（目安10分）です。基本演習までの計画試算は約74～85分です。これは動画の実測時間に、読解・演習等の目安を足した値で、学生による実測値ではありません。

90分は授業全体の目標です。解説が長い回では基本演習を優先し、時間や進度に応じて発展課題を選びます。全部の課題で目安時間いっぱい待つことを求めず、書き終えたら進めます。学生による試用と、全編の発音・抑揚の聴取は未実施です。

毎回の提出は不要です。本人や家族の学校歴・仕事・経験の開示は求めず、人物の設定を使わない資料の分析を選べます。メモは科目全体のレポートA・Bへ再利用できます。
