# 第1回 動画試作

中学校卒業後の多様な学びと進路。2026年11月4日作成。音声は Nanami（Natural）、ja-JP-NanamiNeural。既存の他講義と同じ速度設定（-5%、高さ変更なし）で合成した。

動画の再生時間は **38分07秒**。解説と活動の案内を収め、一時停止して資料読解・クイズ・メモ・小休止に取り組む方式。90分を連続再生する動画ではない。解説・読解70分＋確認活動・休止20分という当初の設計に対し、授業全体の実時間の試用はまだ行っていない。発音・抑揚の全編聴取と時間配分の調整を経て配信する。

動画本体・音声は[配布ページ](https://github.com/zooc-14calbp/industrial-education-ii/releases/tag/video-ii01-comfort-20261104)にある。[動画用PPTX](slides.pptx)／[動画用PDF](slides.pdf)／[字幕SRT](captions.srt)／[字幕VTT](captions.vtt)／[読み上げ原稿](narration.txt)。[学生用ガイド](../../lessons/01/student-guide.pdf)と[課題・評価ガイド](../../assessment/assessment-guide.pdf)を併用する。

## 一時停止の箇所

スライド6で最初のメモ3分、14でクイズ5分、16で休止2分、24で休止3分、28で整理のメモ7分。これらの合計は20分。スライド17と23では指定範囲の読解をそれぞれ5分程度の目安で案内している。長い無音の待機時間は動画内に入れていない。これらを単純に足して90分の授業時間を検証したとは扱わず、試用後に全体を調整する。毎回のメモは提出しない。

## 表示と確認

32枚の構成を維持し、本文の短文化、見出しと本文の強弱、比較図の区切り・関連線を調整した。字幕は画面下80ピクセルの専用帯へ配置し、本文・表・出典と重ならない。背景は淡い灰緑、文字は濃い青灰、強調は落ち着いた青緑を基本とする。冒頭も通常画面と同じ背景にそろえ、字幕は青灰の帯に明るい文字で表示する。図表は編集可能な図形・表で構成した。

1280×720、30fps、5章、字幕348区間。字幕の全文が原稿と一致し、語境界から時刻を作成した。全編のデコード検査、全32スライドの動画フレームと元画像の照合・目視確認を行った。PPTXの配置・構造検査に指摘なし。PDF全32ページのテキスト要素をPPTXと照合した。人による全編の発音・抑揚の聴取と授業の試用は未実施。

初稿の[スライド](../../lessons/01/slides.pptx)も残している。動画の本文と読み上げ原稿はこのフォルダーの組を使う。本人や家族の経験・学校歴の開示は求めず、全員が架空事例または公開情報の整理を理由の説明なしに選べる。
