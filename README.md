## 授業と課題の設計

授業全体90分を目標に、解説・資料読解・段階的な演習・小休止を組み合わせます。動画は全15回の再生時間を実測しました。読解・演習は試用前の目安で、演習4は任意の発展です。毎回のメモは提出せず、科目全体でレポート2本を提出する案です。Aは第9回後に学びの候補を比較（600～800字）、Bは第15回後に進路の選択肢と支援を組み立てます（800～1000字）。既出資料と学習メモで取り組め、字数は負担の目安です。締切・成績への比重・再提出は実施前に確定します。

全員が架空事例または公開情報の分析を理由の説明なしに選べます。本人や家族の学校歴・職業・経験・感情の開示は求めず、開示の有無を評価しません。第13回は中途退学・不登校・進路変更を含む共通回として、事前案内と複数の活動方法を用意しています。普通科・専門学科の双方について、学習と支援の条件を考えます。

成績は提出レポート2本により評価します。課題別のルーブリックは、[課題文と評価基準](assessment/README.md)で確認できます。

## 制作・引継ぎ

スライドはPPTXとPDF、学生用ガイドはPDFで配布します。学生用ガイドの編集元DOCXは別保存します。各回のcontent.jsonに本文、解説メモ、出典と時間の設計を残しています。教材はAIを利用して制作した初稿です。担当者による内容確認と試用を経て配信します。図・写真の追加や収録原稿の推敲は次の検討段階です。

前期の[工業科教育論Ⅰ](https://github.com/zooc-14calbp/industrial-education-i)は別リポジトリです。[利用と出典](RIGHTS.md)を確認してください。未公表研究、第三者資料本体、実際の学生答案、個人情報は収録しません。
