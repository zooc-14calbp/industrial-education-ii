# 工業科教育論Ⅱ

専門高校や高専での学び、その先の仕事と進学を知り、中学校の授業や進路相談でどんな情報を伝えられるかを考えます。

## ここから始める

1. 初めての方は[受講方法](docs/study-guide.md)を確認してください。
2. 下の「各回の教材」から受講する回を選んでください。動画は、問いを考えるときに一時停止できます。
3. [提出課題と評価基準](assessment/README.md)で、科目全体のレポート2本を確認できます。各回のメモや確認問題は提出不要です。
