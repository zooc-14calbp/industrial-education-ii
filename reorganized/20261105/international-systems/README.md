## 図を読む条件

横軸は6〜30歳の共通目盛りです。就学前については図中の注記も参照します。標準的な進み方と課程の配置例を示しており、入学の年齢制限や義務教育の範囲を示す図ではありません。30歳が教育を受けられる上限という意味もありません。

色だけに頼らず、行の見出しと「職業」の表示を併用します。緑には、職業教育を含む高校なども含めています。普通科や専門学科の全てを国際統計上のVETに分類したという意味ではありません。大学にも職業教育があり、色の区分は厳密な統計分類ではありません。

破線は期間・開始年齢が変わる課程、または配置例です。専門学校、ドイツの職業教育、フィンランドのVETの箱の終端を、全国一律の修了年齢として読みません。フィンランドの下2行の帯は学習形態と資格の種類の説明であり、在籍年齢・修業年限を表しません。

横に並ぶ箱は説明上の配置です。その列の進路にしか進めないという意味ではありません。各図の「主な接続」と「条件を確認する接続」も合わせて読みます。国を越えて箱の名前が似ていても、同じ制度・資格とは限りません。箱の幅は学生数や進学率を表しません。

## 省略せず注記に残したこと

- 日本：義務教育学校・中等教育学校、定時制・通信制、特別支援学校等、高専専攻科、大学編入、6年制大学課程、専門職大学院、年齢を一律に定めない教育の存在。
- ドイツ：州差、基礎学校6年の例外、複数の前期中等経路、学校中心の職業教育、職業系の進学経路、上級職業教育、成人の第二の教育経路、芸術・音楽・国家試験等の高等教育、博士への多様な経路。
- フィンランド：9年一貫の基礎教育、TUVA、個別の学修期間、雇用契約の有無が異なる職場での学習、継続・専門の職業資格、UAS修士前の実務経験、博士・Licentiate、成人の学び。

個別の入学資格、編入学年、学位授与、免許の取得、費用や就学義務をこの図だけで判定しません。出願資格と選抜を経た入学も区別します。支援や経路の変更を、一部の学校種だけの課題として扱いません。

## 講義での使い方

[新第11回](../ii-11-explanation.md)で教育段階・VET・統計の分母等を説明し、[新第12回](../ii-12-explanation.md)で図をたどります。図中の一覧を暗記する課題にはしません。講師が日本語で説明し、原資料の外国語読解を追加課題にしません。

Thinking timeは、15歳の架空の生徒に各国の選択肢を説明する一つの演習です。日本と他の1か国から始められます。提出不要で、本人・家族の学校歴や就業経験の開示を求めません。提出レポートは科目全体で2本の方針を維持します。
