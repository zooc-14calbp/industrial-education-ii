## 学び方

1. 学校案内にある科目と、職業情報にある作業を別の欄として読みます。
2. 「考える時間」（スライド24、8分23秒ごろ）で一時停止し、中学生へ紹介する前に確かめたいことを一つずつメモします。
3. 「説明例」（スライド26、9分26秒ごろ）で確認します。毎回の提出は不要です。

1回90分程度は、視聴・資料読解・考える時間・小休止を含む目安です。動画時間のみ実測で、学生による読解・演習時間の試用は未実施です。学校や職場の訪問、本人の経験の開示は求めません。
