## 第5章の節構成

- **第1節　売上・費用・利益を区別する**：スライド4～8。架空の販売記録で数字の意味を確かめます。
- **第2節　商業科の四分野と販売の記録を読む**：スライド9～12。販売の記録と科目の全体像を見ます。
- **第3節　商業科と工業科の情報の使い方を比べる**：スライド13～14。情報を何の判断に使うかを比べます。
- **第4節　卒業時の進路の分母を確かめる**：スライド15～17。図と表を同じ順に読みます。

スライド1～3でこの章の問いと順序を確認します。スライド18で動画を一時停止し、AかBのどちらか一つを考えます。スライド20の説明例と比べます。メモは提出不要です。

[科目・情報・進路の追加読解](../../../../docs/lesson05-commerce-information.md)には、資料の詳しい読み方と進路相談の問いを載せています。

1回90分程度は、視聴・資料読解・考える時間・小休止を含む学習の目安です。動画の実測時間は上記の通りです。受講者による読解・演習時間の試用は未実施です。
