## 第5章の節構成（この回の道筋）

章の入口（スライド1～3）で、何を確かめるかを確認します。以下は[全15章の節構成](../../../../docs/chapter-sections.md)に沿った読み順です。**現行動画には節番号をまだ表示していません。**

1. **第1節　売上・費用・利益を区別する**：スライド4～8で数字の意味を確かめます。
2. **第2節　商業科の四分野と販売の記録を読む**：スライド9～11と補足資料の前半を読みます。
3. **第3節　商業科と工業科の情報の使い方を比べる**：補足資料の活動比較を読みます。
4. **第4節　卒業時の進路の分母を確かめ、相談の問いを作る**：補足資料の図と表を読み、スライド12～14の考える時間に進みます。

スライド15～18で要点と参照先を確認します。[科目・情報・進路の補足資料](../../../../docs/lesson05-commerce-information.md)は、資料読解・考える時間のための増補で、現行動画の内容を置き換えるものではありません。

## 学び方

1. 動画か学習ガイドで例を確認します。ガイドの見出し番号はスライド番号と対応します。
2. 「考える時間」（スライド12、3分39秒ごろ）で一時停止し、表と本文を見ながら考えます。
3. 「説明例」（スライド14、4分27秒ごろ）で自分の説明を確かめます。メモは提出不要です。

1回90分程度は、視聴・資料読解・考える時間・小休止を含む学修目標です。今回示した実測値は動画のみです。受講者の読解・演習時間は未測定で、合計90分の学修が実証済みとは扱いません。時間を埋めるために同じ作業を繰り返す必要はありません。
