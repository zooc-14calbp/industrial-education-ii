## 学び方

1. 冒頭で、この回で知ることと考える問いを確かめます。パンの例で三つの産業部門と職業を区別します。
2. 大阪府の産業連関表を開き、行と列が表す取引の向きを確かめます。続いて学校と産業の図で、校舎の改修から資材・運送へつながる道筋をたどります。
3. 就業者のグラフは画面に表示したまま、対象年、分母、人数の割合を読みます。
4. 「考える時間」（スライド44、16分46秒ごろ）で一時停止します。説明例はスライド46、17分47秒ごろです。短いメモで十分で、提出は不要です。

1回90分程度は、視聴・資料読解・考える時間・小休止を含む目安です。動画時間のみ実測で、学生による読解・演習時間の試用は未実施です。産業連関表の計算は課していません。
