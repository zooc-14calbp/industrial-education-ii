## 学び方

1. パンの例を使い、第一次・第二次・第三次産業と職業を区別します。
2. 学校と産業の図で、学校が発注した工事から資材・運送などへつながる道筋をたどります。
3. 「考える時間」（スライド41、15分10秒ごろ）で一時停止します。説明例はスライド43、16分12秒ごろです。短いメモで十分で、提出は不要です。

1回90分程度は、視聴・資料読解・考える時間・小休止を含む目安です。動画時間のみ実測で、学生による読解・演習時間の試用は未実施です。産業連関表の計算は課していません。
