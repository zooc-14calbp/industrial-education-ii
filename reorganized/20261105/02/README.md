## 到達目標

- 高校・高専・専門学校等を、入学段階と課程の違いで説明できる。
- 学校案内と募集要項を区別し、受験・合格・免状取得を読み分けられる。

## 学修の目安

動画は27枚、実測 **21:17**。Nanami（Natural）、字幕付きです。動画内に演習の待ち時間を入れず、必要な箇所で一時停止します。

| 活動 | 時間 |
|---|---:|
| 動画 | 21分17秒（実測） |
| 指定資料の確認 | 15～20分 |
| 比較表の作成・根拠と確認先の見直し | 35～45分 |
| クイズと確認 | 5分 |
| 小休止 | 5分 |

合計約81～96分の計画で、90分程度を目安とします。読解15分・思考45分等の場合は約91分です。動画以外は学生による試用前の目安で、目安時間いっぱい作業を続ける必要はありません。

## 中心の問い

学校制度・学ぶ活動・資格・卒業後の経路・支援や条件の五つの観点で、A・Bの事実、未確認事項、次の確認を一枚の表にする。

架空の工業高校・高専の案内を同じ観点で読みます。分母不明の就職率100％と卒業者中60％をそのまま順位付けせず、第一種電気工事士試験の合格と免状取得も分けて確認します。未記載は「存在しない」と断定せず、次の確認を残します。

毎回の提出はありません。人物を設定しない資料分析で取り組め、本人や家族の学校歴・経験・生活事情の開示、AIへの登録、実際の資格試験への申込は不要です。科目全体の提出レポートは2本です。
