# 工業科教育論Ⅱ 再編案の増補教材

[Ⅰ・Ⅱ共通の基本方針](../../../docs/teaching-policy.md)では、日常の例から言葉の意味をつかみ、知識を仕事や授業の判断に使うまでの流れを示しています。

第9回では、話し合いに必要な資料と読み方をそろえ、最後に各自の理解を確かめる授業例を扱います。[話し合いの条件と関連論文](../../../docs/active-learning-discussion.md)

説明スライドには、各回の内容を読む手がかりになる言葉を一つ添えました。意味がはっきりしているところはそのまま先へ進み、迷うところは本文の問いと答えで確かめられます。

この講義では、身近な場面で言葉の意味をつかみ、資料や原文の該当箇所に戻って、自分の言葉で説明する練習をします。各回の本文にある「言葉を使って確かめる」は、聞き覚えのある言葉を一つの場面で使ってみる短い問いです。答えは同じ箇所で確認でき、提出は不要です。指導要領を読む回では、まず確かめたい問いを決め、どこを開けばよいかを練習します。

## 授業時間の考え方

動画視聴・資料の確認・考える時間・小休止を含め、1回90分程度を目安に学修します。動画自体を90分にする必要はなく、「70分＋20分」も固定の配分ではありません。時間を埋めるための説明や課題は加えず、到達目標の理解と受講生の負担を基準に調整します。
